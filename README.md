# morse — 摩尔斯电码编码 / 解码

纯标准库、纯本地的小工具：文本 ⇄ 摩尔斯电码，外加一个学习用的点划时序图。

```bash
python3 -m morse encode "HELLO WORLD"
# .... . .-.. .-.. --- / .-- --- .-. .-.. -..

python3 -m morse decode ".... . .-.. .-.. ---"
# HELLO

python3 -m morse timing "SOS"
# · · ·   − − −   · · ·
```

## 命令

| 命令 | 说明 |
|---|---|
| `encode TEXT` | 文本 → 摩尔斯码（字母间空格分隔，词间用 `/`） |
| `decode CODE` | 摩尔斯码 → 文本 |
| `timing TEXT` | 点划时序图：`·`=1 单位点，`−`=3 单位划 |

通用参数：`--stdin`（从管道读取）、`--json`（机器可读输出）。

## 码表

支持 A–Z、0–9 和常用标点：`. , ? ! / = + - :`。大小写不敏感（统一转大写）。
不支持的字符编码时跳过并给出警告；解码时遇到未知码用 `?` 代替并警告。

## 设计取舍

- `--audio`（播放声音）不在范围内：终端发声依赖系统播放器且各平台差异大，超出"小巧"定位。
- 时序单位按国际标准：点=1、划=3、点划内间隔=1、字母间隔=3、词间隔=7。

## 已知局限

- 只做字符级编解码，不做纠错：发报时的手误码解出来就是错字。
- 中文没有标准摩尔斯码，中文字符会被跳过（警告提示）。
